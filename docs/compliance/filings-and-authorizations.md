## 1. 归档字段标准

| 字段 | 要求 |

| 主体 | 与营业执照/合同一致的完整名称、统一社会信用代码或等效标识 |

| 日期 | 发布、申请、批准、生效、到期和本次核验日期 |
| 适用范围 | 产品、包名/签名、地区、版本、字段、期限和转授权边界 |
| 证据 | 原件/签章 PDF、后台截图、哈希、归档路径和保管人 |
| 状态 | `[已取得]`、`[待运营提供]`、`[待官方来源核验]`、`[待真机复核]`、`[待律师复核]` 或 `[未找到]` |
