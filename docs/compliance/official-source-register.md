## 3. 归档要求

每份来源至少保留：

1. 官方页面 URL、页面标题、发布机关、文号、公布日期、生效日期。
2. 抓取日期、页面快照或 PDF、SHA-256、归档编号和保管人。
3. 与项目功能、字段、权限、留存和删除路径对应的适用性分析；不得只保存链接。
4. 律师对关键义务和上线门槛的书面意见编号；律师须逐项说明适用性、例外和待补事实。
5. 来源更新、平台规则变更或功能变化后的复核记录。

## 4. 禁止写法

- 禁止写“根据记忆，平台要求……”。
- 禁止写“行业通常都这样做，所以合规”。
- 禁止把已读取正文写成“已经备案”“已获批准”“平台已授权”或“律师已签字”。
- 禁止把模型供应商自述等同于官方备案、平台审批或合同证据。
- 禁止在版本、日期、适用性和业务事实未核验时写成确定结论。
