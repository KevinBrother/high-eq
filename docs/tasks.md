# 开发任务与交接

36 个任务编号（T32 分两次独立交付），分 8 个阶段。编号是稳定引用，不代表执行顺序；新增的 T36 在 P0 启动。

## 使用方法

- 每个会话读取本卡、[一页决策摘要](DECISIONS.md)、`docs/CONVENTIONS.md`（T01 产出）、阶段公共输入、本卡列出的文件和已完成依赖的 `docs/tasks/Txx.md`。脚手架任务不读取自己的交接；客户端可先用契约模拟，后端就绪后由客户端任务切真实接口联调。
- App 和后台的唯一接口契约分别是 `docs/api/app.yaml`、`docs/api/admin.yaml`。后端任务可改自己模块的接口并新增时间戳迁移，同步更新 `docs/schema.md`；跨模块问题记入 `docs/CHANGES.md`，由负责模块解决。
- 每张卡按目标、验收和“不做”交付，并写 `docs/tasks/Txx.md`。真机、商户、真实模型、标注、云账号与审核结论由项目方确认；没有设备或凭据时交付可复现脚本和人工清单，不以模拟结果代替。

```text
            → P6 情绪感知·客户端 T28 T29 T31 T32B

```

客户端先按契约开发，需要真实后端时再联调。每张卡的“依赖”一栏是精确到任务的依赖。

## P0 工程约定

T01–T03 建立工程地基；手表验证在本阶段单独启动。

### T01 仓库结构与项目约定文件

- **依赖**：无
- **背景**：做一个情商训练 App。客户端 Flutter（iOS/安卓），后端 Go（Gin + oapi-codegen，单体按模块划分），PostgreSQL + Redis，运营后台 Flutter Web，Apple Watch 小应用用 Swift。后续由多个独立 AI 会话分别开发各模块。
- **输入**：`docs/architecture.md` 的架构、客户端与后端章节；本文件使用方法、`docs/DECISIONS.md`。
- **目标**：建 monorepo 骨架（`app/`、`server/`、`admin/`、`watch/`、`docs/`）；在约定中固定 Gin + oapi-codegen、golang-migrate、Riverpod，以及 T10 七类任务的英文常量。摘要直接引用，不另存历史决策。
- **交付**：目录骨架；`docs/CONVENTIONS.md`（技术栈与版本、目录职责、命名、错误码、日志、接口风格、分支与提交规范、交接说明模板）；`docs/CHANGES.md` 空模板。
- **验收**：约定文件不超过 3 页、每条可执行；一个没看过本项目的人读完能知道代码放哪、怎么命名。
- **不做**：业务代码、数据库表、接口定义。

### T02 数据库模型设计

- **依赖**：T01
- **背景**：后端模块有用户与会员、测评（WLEIS，16 题、四维度、1–7 分）、情绪识别（个人心率/语速基线、情绪波动事件）、画像（用户画像 + 关系人画像，大五人格 / 冲突风格 / 依恋类型 + 把握度）、训练计划、对练会话与评分、复盘、模型配置与路由、提示词版本、AI 调用日志。原始录音不入库。
- **输入**：全部任务卡、`docs/standards.md`、`docs/standards/privacy.md`、`docs/standards/scoring_prompt.md`。
- **目标**：设计 PostgreSQL 表结构和索引，写成可执行的迁移脚本。 用户表存时区（默认 Asia/Shanghai）、年龄确认与同意记录；设计会话扣退账本和评分源记录到 T26、日志的关联键。手动标记独立建模（时间、可空对象/场景），支持按账号在 60 秒内去重。防重放记录仅存不含身份信息的源 ID，用存储 TTL 清理。传感器只存 30 秒统计与事件，录音不入库。 内部用户 ID 是唯一身份；登录方式、购买归属均映射至它。区分单项进度与整场评分；给对练用户消息、回复/复盘请求设计去重键。
- **交付**：`server/migrations/` 迁移文件；`docs/schema.md`（ER 图 + 每张表用途）。
- **验收**：迁移在空库上可正反向执行；敏感字段（日记、画像、密钥）标注为加密字段。 按隐私清单标明各副本的用途、加密、保留、导出和级联删除键；敏感字段 AES-GCM 加密，不依赖密文检索。
- **不做**：Go 代码、接口。

### T03 API 契约

- **依赖**：T01、T02
- **背景**：App 与后台只依赖 OpenAPI 3 契约；对练走 SSE，回复助手一次返回审核后的完整 JSON。
- **输入**：全部任务卡、`docs/schema.md`、`docs/architecture.md`、`docs/standards.md` 及评分、隐私、扣次规范。
- **目标**：写出全部对外接口的 OpenAPI 3 定义（App 与后台分两个文件），流式接口用 SSE 并写清事件格式。 约定会话 ID、历史恢复和扣退结果，SSE 的 safety 终止事件；非流式危机返回 `{safety: true, message}`。区分本人波动、对话节奏和手动标记；定义免费标记创建/历史接口（60 秒内返回同一记录）和会员画像汇总接口。区分对练流式片段与完整回复已审核并保存的状态；特征载荷为 30 秒统计。定义画像摘要、标注、同意、导出和删除接口。 契约区别单项进度与整场评分；账号绑定/冲突选择、购买归属、消息 ID 与请求 ID 幂等；审核故障返回可重试 `moderation_unavailable`（非流式 503，流式同名终止事件），与 `safety` 分开。基线进度按信号返回有效时长或读数、就绪状态及原因。
- **交付**：`docs/api/app.yaml`、`docs/api/admin.yaml`。 事件目录列名称、发布/订阅方与载荷：测评完成 T08→T26、评分完成 T19/T23→T26（仅数值和关联键，携带评分前已分配的不可复用源 ID；重投不改变事件的原始发生时间）、画像反馈 T21/T23/T30→T25、删除/导出→各数据模块。
- **验收**：通过 OpenAPI 校验；每个接口有请求/响应示例和错误码；会员限次的返回格式统一。
- **不做**：实现代码。

### T36 Apple Watch 真机与审核路径验证（P0 提前启动）

- **依赖**：无；与 T01 并行，不依赖正式 App、订阅或 T31。
- **输入**：`docs/standards/watch.md`、`docs/standards.md` 第五节。
- **目标**：以最小 Swift 原型，在配对真机记录对话会话、锁屏/切后台、实时心率与步频、手机往返震动、断连、结束采集和耗电。准备按真实用途提交的审核说明、权限理由、演示步骤和失败时的关闭方案。
- **交付**：`docs/tasks/T36.md` 分开记录技术结论（待验证/通过/不通过）和该版本苹果正式审核状态（未提交/审核中/放行/未放行），附设备、条件、结果、材料、负责人及证据。
- **验收**：真机技术验证通过即可交接 T31 开发和送审，无须先有苹果批准。只有对应版本正式放行才能在生产启用并在会员页宣传。两栏都不得凭材料准备或模拟结果标通过。
- **不做**：正式手表产品、代替平台审核作结论。

## P1 后端基础

本阶段每个任务的输入都包含 `docs/CONVENTIONS.md`、`docs/schema.md`、`docs/api/app.yaml` 和 `docs/tasks/T04.md`，下面只列额外输入。

### T04 Go 服务脚手架

- **依赖**：T01、T02、T03
- **背景**：后端是 Gin 单体，用 oapi-codegen 从 `docs/api/app.yaml` 生成接口层，模块有：用户与会员、测评、情绪识别、画像、训练计划、模型网关。
- **目标**：搭好可运行的服务骨架：配置加载、PostgreSQL / Redis 连接、统一错误与日志、鉴权中间件占位、健康检查接口、字段加密工具、各模块空目录。 实现单体事件发布/订阅和删除、导出钩子，把 T03 事件目录引入 CONVENTIONS。所有存用户数据的模块必须注册两个钩子。评分事件可重放期 30 天；删除或注销清理时，原子登记相关源 ID 并清除业务记录，防重放记录仅含源 ID，TTL 不短于 30 天和最长可恢复备份保留期二者的较大值。消费时拒绝过期、命中删除记录或来源/账号已不存在的事件；与并发删除协调，不允许先检查后回填已删数据。AES-GCM 开发密钥用环境变量，上线接 KMS。
- **交付**：`server/` 代码；`docker-compose.yml`（本地 PG + Redis）；`docs/tasks/T04.md`（如何新增一个模块和接口）。
- **验收**：一条命令启动；迁移自动执行；健康检查返回 200；有单元测试示例。
- **不做**：任何业务逻辑。

### T05 用户与认证

- **依赖**：T04
- **背景**：国内用户为主。iOS 上如果提供第三方登录，必须同时提供 Apple 登录。
- **额外输入**：`docs/standards/privacy.md`。
- **目标**：手机号验证码登录、Apple 登录、微信登录；JWT 访问令牌 + 刷新令牌；注销账号（含数据删除）。 记录各项同意的版本、时间和撤回状态；注册确认满 14 岁。注销后冻结 15 天，登录可撤销，期满调用各模块删除钩子。 首次登录建立内部用户 ID；已有账号的其他登录方式在设置显式绑定并验证。若已归属另一账号，展示冲突并让用户选择保留当前账号或验证后切换原账号；不自动合并账号、数据或权益。
- **交付**：用户模块代码与测试；短信、第三方登录用接口抽象，开发环境可用假实现；`docs/tasks/T05.md`。
- **验收**：验证码 60 秒一次、每日最多 10 次；冷静期内可恢复，期满按隐私清单删除各副本，订单脱敏保留；完成注销后重放旧评分事件，不得重建账号或其数据。 同一已绑定身份换设备仍回到原 ID；冲突取消不改变任一账号。
- **不做**：会员、支付。

### T06 会员权益与限次

- **依赖**：T05
- **背景**：免费含测评、雷达图、小练习、卡片、通用计划、1 个关系人；对练、回复、文字复盘各每天 3 次。所有用户可不调用模型地手动标记并查看自己记录，不验会员或 AI 额度。会员以上不限，另享手表自动提醒（对应版本获苹果正式放行后）、录音与心率对齐回放、按对象和场景汇总的个人情绪画像及个性化计划；权益跟账号跨平台。
- **额外输入**：[共用扣次表](standards/quota.md)、`docs/DECISIONS.md`。
- **目标**：权益配置（写在配置里，不写死在代码中）、权益校验中间件、基于 Redis 的每日限次计数、查询剩余次数接口。 同一 session_id 幂等结算，第一条完整 AI 回复审核通过并保存、可按会话 ID 拉取时才入账，评分失败/危机退回原日。回复与文字复盘成功才扣；失败或危机不扣。会员到期停止采集，关系人仅 1 个继续使用。
- **交付**：代码与测试；`docs/tasks/T06.md`（其他模块如何声明“需要会员”或“扣一次”）。
- **验收**：零点重置按用户时区；并发请求不超扣。 逐行覆盖共用表，含跨日退款和重连。免费用户即使文字复盘额度为零仍能标记、看历史；不能开启会员采集、对齐回放或画像汇总。
- **不做**：支付接入。

### T07 支付与订阅

- **依赖**：T06
- **背景**：iOS 自动续期月/年订阅；安卓微信、支付宝一次性月/年卡，不自动续费。
- **目标**：苹果收据校验与 App Store Server Notifications；微信/支付宝下单与回调；统一的订阅状态机（生效、续期、过期、退款）。 发起 iOS 购买时用与内部用户 ID 稳定关联的 appAccountToken；服务端用已校验交易解析归属，恢复购买不以当前登录者覆盖原归属。
- **交付**：代码与测试（回调用模拟数据）；`docs/tasks/T07.md`（上线前需要申请的商户资质清单）。
- **验收**：回调幂等；签名校验不过则拒绝；订阅变化实时反映到 T06 权益。 安卓卡仅在 iOS 未覆盖的时段消耗，iOS 续订顺延安卓剩余天数。 含跨端、重装恢复购买、重复通知、退款。当前账号与原购买账号不同则提示验证并切换，不静默转移会员。
- **不做**：客户端支付界面。

### T08 测评服务（WLEIS）

- **依赖**：T05
- **背景**：WLEIS 共 16 题，四个维度各 4 题，每题 1–7 分，维度得分为各题平均。题目原文见 docs/wleis_items.md（作者授权版本）。每四周可复测一次。
- **额外输入**：`docs/standards.md` 第二节、`docs/wleis_items.md`。
- **目标**：题库从配置加载；提交答卷、计分、生成四维雷达图数据、历次对比。 16 题答全才计分并发测评完成事件给 T26；未满 4 周拒绝复测并返回可复测时间。
- **交付**：代码与测试；按 `docs/wleis_items.md` 的 YAML 加载题库；`docs/tasks/T08.md`。
- **验收**：计分用例覆盖边界值；换题库不改代码。 用未取整的百分制值在 40、60、75、90 分界前后分档，再取整展示；例如 59.9 显示 60 但仍为 L2。
- **不做**：AI 评分、训练计划生成。

## P2 AI 层

输入同 P1 的公共四件。核心规则：业务代码只传任务名，用哪个模型由网关按数据库配置决定；换模型只有运营后台能操作。

### T09 模型网关核心

- **依赖**：T04
- **背景**：要接的有国内云端模型（DeepSeek、通义千问、豆包，大多兼容 OpenAI 格式）和 vLLM 私有部署的开源模型。
- **目标**：对内一套 Chat 接口（普通 + 流式 + JSON 结构化输出）；按服务商写适配器；从数据库加载模型配置，密钥加密存储；配置变更通过 Redis 通知热更新。 模型、审核及其备用服务走同一国内准入清单：处理和存储均在境内，不出境，记录发送字段、留存期限、删除方式和条款证据。优先能签不留存或短期留存条款的服务商。
- **交付**：`server/` 网关模块与测试（用假模型服务）；`docs/tasks/T09.md`（业务模块调用示例、新增适配器步骤）。
- **验收**：改配置后不重启即生效；新增一个 OpenAI 兼容模型只需加一条配置。 模型适配器不记录请求/响应正文、完整提示词或密钥。 无准入记录或去向/留存不明的配置无法启用。
- **不做**：路由策略、灰度、提示词。

### T10 任务路由、备用切换与调用监控

- **依赖**：T09
- **背景**：任务类型：角色扮演、回复建议、评分、画像推断、复盘分析、内容生成、简单分类。
- **额外输入**：`docs/standards/scoring_prompt.md` 固定危机提示、`docs/standards/privacy.md` 日志清单。
- **目标**：每类任务配主模型 + 备用模型；主模型失败或超时自动切备用；按用户比例灰度到新模型（同一用户始终命中同一组）；每次调用记录任务、模型、耗时、token、成本、是否失败。 首 token 超时 10 秒、总时长 60 秒。输入和输出接可替换审核服务；流式逐句缓冲，审核通过才发；危机发 safety 并结束，不走备用继续生成。非流式返回统一求助对象。日志仅统计值与关联 ID，无原文、评分理由或模型回复。 审核无结论或服务故障走独立技术错误：立即停止输出，发 moderation_unavailable，显示“服务暂不可用，可重试”，不评分、不扣次或退回已扣，不发危机提示。流式首段已发后不得切备用拼接；首段前也只能切到满足相同数据条款的备用。
- **交付**：代码与测试；供后台看板用的统计查询接口；`docs/tasks/T10.md`。
- **验收**：模拟故障成功切换；10 万用户灰度比例误差 ±1%；危机不评分、不扣次；统计可按模型和提示词版本关联。 分别注入危机命中、首段前审核超时和首段后审核中断，断言终止事件、替换文案、无后续片段及净扣次为零。
- **不做**：后台页面。

### T11 提示词模板与版本管理

- **依赖**：T09
- **目标**：提示词按任务存储、带版本号和变量占位；支持发布、回滚、与模型搭配做 A/B；每次调用记录所用版本。 先定模型灰度组，再在同一模型内做提示词 A/B；日志只关联版本 ID，不保存渲染后的提示词。
- **交付**：代码与测试；`docs/tasks/T11.md`（模板语法、业务如何引用）。
- **验收**：回滚后新请求立即用旧版本；变量缺失时报错而不是静默发出。
- **不做**：具体提示词内容。

### T12 AI 评分细则与评分提示词

- **依赖**：T10、T11
- **背景**：对练结束评整场一次；复盘只评“我当时怎么做”；回复助手不评分。不按场景改变权重。
- **额外输入**：`docs/standards/scoring_prompt.md`（提示词、Schema、期望输出）、`docs/standards/quota.md`、`docs/standards.md`。
- **目标**：交付 Go 包 `Score(ctx, scene, context, utterance, profile)`；按原顺序标记用户轮次，整场取主导 mode，改写问题最大的一轮。Schema 失败重试一次，最终失败返回状态供 T19 退款；危机不评分。T10 只关联评分 ID / 数值，不写理由。 单项另走仅评声明目标项的接口，不评其余项、不发成长评分事件；审核故障不是模型判危机。
- **交付**：提示词种子；`server/eval/` 评测集与脚本；保留 10 条基础样例和 2 条回归，另起草 20 条（至少 5 条多轮），期望分标“待人工复核”；`docs/tasks/T12.md`。
- **验收**：两条回归锁定无事实扣分、80 字及从 1 起的用户轮次；真实模型每条跑 5 次，NVC 标准差 ≤5、情绪维度极差 ≤1、格式 100% 合规，准确性按评分规范人工复核。 受控抽检真实案例，仅用虚构对话加入回归库，评测文件不含真实原话、用户/源评分 ID 或关系人信息。
- **不做**：对练会话逻辑。

### T32A 免费手动标记（P5 可并行，T32 第一次交付）

- **依赖**：服务端用 T04/T05，客户端用 T03/T16；文字复盘入口先按契约开发，联调接 T23/T24。不依赖手表、语音、T30、T31 或苹果审核。
- **输入**：P1/P4 公共输入、`docs/standards/privacy.md`、`docs/standards/quota.md`。
- **目标**：负责标记创建及本人历史的接口和页面。点击即存时间，对象、场景可后补；同账号从上一条新建记录起不足 60 秒返回原 ID，不延长窗口，满 60 秒可新建，同一请求重试不重复。可跳转文字复盘并预填时间、对象、场景；不调用模型、不申请传感器权限。
- **验收**：免费且额度已用尽、无手表/麦克风授权仍可创建、查看；并发、59 秒重复点击仅一条，60 秒可新建。打开复盘或存草稿不扣，提交 AI 文字复盘成功才扣；复盘额度耗尽不阻断标记。跨账号不可见，注册导出及删除钩子。
- **交付**：服务端接口、页面、验收记录及 `docs/tasks/T32A.md`。不做会员分析或采集。

## P6 情绪感知

后端用 P1 公共输入，客户端用 P4 公共输入。

本阶段最复杂，放在最后。共同原则：App 被动采集、主动提醒，用户只负责事后核对；原始录音只在手机本地处理，只上传特征和时间点；所有采集都要用户主动授权。

### T28 健康数据接入（客户端）

- **依赖**：T16
- **背景**：用 `health` 插件读 Apple 健康与安卓 Health Connect，华为用官方 Flutter 插件；安卓和华为手表的数据有几十秒到几分钟延迟。
- **额外输入**：`docs/standards/watch.md`、`docs/standards/privacy.md`。开工前由项目方申请华为心率权限。
- **目标**：仅会员可开启；单独同意后再申请系统权限，采集前检查 consentProvider，到期或撤回立即停。读历史心率、HRV、步数、训练状态；安卓申请运动识别并读取手机步频。实时 Apple Watch 桥接归 T31。只上传 30 秒窗口均值、最大值、样本数及运动标志。
- **交付**：代码及 `docs/tasks/T28.md`（平台、真机延迟、缺失数据）。安卓/华为历史数据只供基线和事后复盘。
- **验收**：拒绝授权时其他功能正常；三类平台至少各在一台真机上验证。 HRV 只有零星读数或完全没有时不影响其他信号就绪；断网期间撤回权限，恢复联网不得补传此前未发窗口。
- **不做**：情绪判定、Apple Watch 端应用。

### T29 本地语音特征提取（客户端）

- **依赖**：T16
- **背景**：本机计算音量、音调及语速；混入对方声音时不能据此认定用户本人情绪。
- **额外输入**：`docs/standards/privacy.md`、`docs/standards.md` 第五节。
- **目标**：仅会员可开启；单独告知混音风险后请求系统麦克风权限，录音保留另行同意，默认关。采集前检查 consentProvider；撤回或到期立即停。逐秒特征与转写只留本机，按 30 秒聚合上传；录音可回听、3 天自动删，录制时始终显示状态。
- **交付**：代码与测试；`docs/tasks/T29.md`（方案取舍、耗电实测）。
- **验收**：抓包无音频或转写上传；真机连续录 30 分钟耗电 ≤5%；拒绝录音保留不妨碍已授权的特征分析。 纯静音不累计人声秒数；混音仅描述对话波动，不归因为本人。撤回后联网不补传，关 App 超过 3 天重开时先清过期录音，历史页不可回听。
- **不做**：情绪判定。

### T30 情绪识别服务（后端）

- **依赖**：T04
- **背景**：后端计算基线、下发阈值，实时判定在手机。本人波动必须含实时心率异常；语音双异常只能提示对话节奏。
- **额外输入**：`docs/standards.md` 第五节、`docs/standards/watch.md`。
- **目标**：提供 Go 参考实现与 JSON 测试向量。心率、各语音特征分别满 7 个有效日后参与（心率按有效时长、人声按该特征有效秒数，每天满 30 分钟）；HRV 按离散读数/采样日展示趋势，永不阻塞提醒；同一 30 秒窗口判定，运动排除，冷却 10 分钟。接收窗口统计和分类事件，180 天滚动清理；本人误报标“不是”时对应阈值上调 5%，不超初始 1.5 倍。仅将明确本人反馈送 T25。免费标记的服务端接口归 P5 的 T32A，本卡不重复实现。
- **交付**：代码与测试（用合成数据）；`docs/tasks/T30.md`。
- **验收**：覆盖用户沉默、对方激动（心率正常或缺失，两类语音异常）：只返回对话节奏、无自动画像更新。另测心率单异常不触发、心率＋语音、运动、冷启动、冷却、安卓历史心率不参与。 分别覆盖心率未就绪、只有部分语音特征就绪、人声不足和无 HRV；返回各项进度及原因，不用 HRV 或沉默填时长。
- **不做**：客户端界面、提醒推送。

### T31 Apple Watch 小应用

- **依赖**：T28、T36 技术验证通过；不以苹果正式批准作为开发或送审前置条件。
- **背景**：只负责两件事：持续读心率，和收到手机指令后轻震提醒；通过 WatchConnectivity 与手机通信。
- **额外输入**：`docs/standards/watch.md`、T36 验证记录。
- **目标**：按技术验证通过的范围实现并送审 Swift 工程及 app/ios 桥接：用户显式开启对话模式，手表经 WatchConnectivity 发送实时心率和 CMPedometer 步频；手机询问是否录音，不自动开启。结束时停止采集。
- **交付**：代码；`docs/tasks/T31.md`（消息协议、后台运行限制）。
- **验收**：正式放行前可在测试环境真机验证指令发出数秒内轻震、重连补传不触发过时提醒；未放行保持生产关闭并记录原因，不阻塞手动标记。
- **不做**：手表上的复杂界面。

### T32B 会员情绪辅助（P6，T32 第二次交付）

- **依赖**：T24、T25、T28、T29、T30、T32A；手表自动路径另需 T31，生产启用须对应版本正式放行。其他会员功能不等待苹果审核。
- **输入**：P6 客户端公共输入、`docs/standards.md` 第五节、`docs/standards/watch.md`、T30 JSON 向量。
- **目标**：Dart 实现同窗双信号规则；语音只说明对话节奏，不能证明谁在激动。显示各信号基线进度和未就绪原因，HRV 仅趋势。本人提醒须有异常实时心率参与；只有两类语音异常时只提示“刚才对话节奏有变化，要标记吗？”，不自动更新个人画像。交付录音与心率按本地时间对齐回放、本人核对及按对象/场景汇总的会员画像。
- **验收**：通过 T30 全部向量；用户沉默、对方激动且本人心率正常/缺失，只提示对话节奏，不发本人画像反馈。安卓不发本人自动提醒；已放行 Apple Watch 真机验收心率＋语音同窗后轻震。会员到期后关闭会员功能但仍可查看手动标记。文案禁用词及 10 条示例。
- **交付**：会员页面、联调记录、`docs/tasks/T32B.md`。不做算法调参或重做免费标记服务。

### T33 隐私与合规材料

- **依赖**：T17、T28、T29（可与 P5 并行开始）
- **背景**：面向国内用户；采集心率、HRV、语音特征、情绪日记和关系人信息；使用大模型生成内容，需做生成式 AI 相关备案；WLEIS 已获商用授权，授权函需归档。

- **目标**：隐私政策与用户协议草稿；各权限弹窗文案；敏感数据清单（字段、存放位置、是否加密、保留期）；备案、ICP、应用商店审核、量表授权的待办清单。
- **交付**：`docs/compliance/` 下的文件。
- **验收**：清单逐项对齐 schema、原始记录和副本，含安卓运动识别、对练消息、评分引用、数值副本及日志关联 ID；文案禁用词和 10 条示例；逐项核对主模型、备用模型、审核服务的境内处理与留存/删除条款凭据；上线前律师审阅。

### T34 部署、CI/CD 与线上监控

- **依赖**：T04、T10、T13、T16
- **背景**：云无关 Linux + Docker Compose：Go 单体、PostgreSQL、Redis、Flutter Web 静态站点；本轮不用对象存储。
- **输入**：`docs/CONVENTIONS.md`、`docs/tasks/T04.md`、`T13.md`、`T16.md`。
- **目标**：容器化；测试与生产两套环境；提交即跑测试、合并即部署测试环境；App 打包流水线；日志、告警（含 AI 成本异常告警）、数据库备份。
- **交付**：Dockerfile、流水线配置、基础设施说明；`docs/tasks/T34.md`（发布与回滚步骤）。
- **验收**：任意 Linux 主机按说明部署与回滚一次成功；日 AI 成本超过 7 日均值 2 倍告警；云上部署、KMS 和备份恢复另附操作说明。 备份清单含最长可恢复期限；删除记录独立保存，保留期 ≥ max(30 天, 最长备份期)。用删除前快照在隔离环境恢复，先按最新删除记录清除源数据与副本，验证已删复盘和注销账号不可查询、导出或恢复，再开放流量与消费者。删除记录不完整则禁止开放。
- **不做**：业务代码。

### T35 “我的”页与个人信息权利（客户端 + 后端）

- **依赖**：T05、T06、T16、T28、T29、T30
- **背景**：《个人信息保护法》要求用户能查阅、复制（导出）、更正、删除自己的信息，并能撤回同意。各功能的单独同意弹窗在各自任务里做，这张卡做统一管理入口。
- **额外输入**：`docs/standards/privacy.md`。
- **目标**：隐私设置逐项撤回并立即停采；查阅、更正、删除和导出。通过模块钩子按需流式生成 JSON 压缩包，不落盘。注销冻结 15 天，登录可撤销；提醒先在苹果设置取消订阅。 设置提供其他登录方式的手动绑定、重新认证及冲突选择，不自动合并。
- **交付**：页面和接口代码；`docs/tasks/T35.md`。
- **验收**：按补全的隐私清单逐项验收导出与删除：用同一会话从源消息、带引用的评分明细追到 T26 数值副本和可关联日志；单条删除后重算且不可再导出，导出覆盖手动标记的时间、对象和场景。按隐私清单跑两组反序用例：删除复盘后重放评分事件，训练参考分和再次导出均无回填；注销清理后重放，不恢复账号、评分或可导出数据。除脱敏订单等清单例外，防重放仅保留源 ID，覆盖 30 天重放期及最长可恢复备份期后清理。撤回手表同意后不再读取健康数据。 联同 T34 验收备份恢复后的删除效果，及换账号、撤回后联网、过期录音重开三组设备端场景。
- **不做**：各功能自己的同意弹窗。
