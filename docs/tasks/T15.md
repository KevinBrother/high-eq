# T15 · 模板发布与调用监控

交付基线：`af58a76dcbcb8c63cf6b3b36f236cb5c2e3c93d7`。后台入口 `/prompts`、`/metrics` 对运营和超级管理员开放。本卡不改变模型路由、评分规则或源数据保留期，无迁移、无预置模板、无看板缓存。

## 运营操作

1. **模板管理**：选任务，读取服务存量。可从空白开始，也可选已有版本编辑。保存追加不可变版本，不动线上配置；版本比较使用两份已保存的原始模板，折叠相同的首尾行，不渲染变量。
2. **按模型发布**：选生成模型及主版本，可选同任务的不同实验版本与 0–100% 占比。看到的是 T11 的实际发布指针；发布只写一次。模型目录包含还没有发布指针的目标；停用模型明确标识，发布不会启用模型。运营可读 `/admin/v1/prompt-models` 的 `id/name/enabled`，不能读 T14 的受限模型配置。审核服务不是模板目标。
3. **回滚**：在目标任务/模型下直接点「回滚到 vN」。一笔 `PUT /admin/v1/prompt-releases` 改主版本、清空实验版本并将比例置零；随后重新读取线上状态。T11 的网关按下一次尝试读主库，在途请求不被撤销。写操作继续走 T13 的审计事务。
4. **监控看板**：选最近 24 小时、7 天或 30 天，可按任务、模型 UUID、模板版本 UUID 筛选。点「查询调用」重新取数；「加载更多分组」复用同一组条件与起止时间。没有记录时显示空态，不显示演示数据。

## 统计与隐私边界

- `GET /admin/v1/metrics` 以 `ai_calls.started_at` 取 `[from,until)`；默认 24 小时，最大 31 天。实际调用的任务、模型和版本（允许 NULL）组成一组；不是按现在的发布指针推断。主备、重试和审核各算一次。`failures` 为非 `ok` 次数；`failure_rate=failures/calls`，耗时取记录的毫秒数算术平均。
- `cost_cny` **仅为已知成本小计**；`unpriced_calls` 是 `cost_cny IS NULL` 的尝试数。已知零元与没有报价/没有用量是两种情况。
- 同页在只读、可重复读事务内查询。仅对成功评分调用的 `score_id` 在组内去重，读取 `growth_scores.nvc_enc` 的数值对象：T04 信封，AAD 为 `growth_scores.nvc_enc/<score UUID>`，取整数 `total`（0–100）。未生成的投影计入 `missing_score_values`，不是零分；无法解密或无效总分返回错误，不返回部分分布。T26 写侧仍需按此约定联验。没有关联评分的普通调用不计作评分。
- 不读 `scores.detail_enc`、情绪理由、活动正文或消息；不持久化直方图，不将模板、变量、引文、原话、渲染结果写入日志。响应不含账号、活动或源评分 ID。删除源后下一次查询按现存记录重新计算。

## 实测和复验

隔离的基线源码，只使用合成记录，不接生产服务或供应商。Docker 套接字和本地监听受限，因此数据库路径用 **PGlite 0.3.2（PostgreSQL WASM）** 执行基线全部 up SQL；经管道连接 pgx，由真实 Gin 路由、鉴权、发布事务及 SQL 完成验证。未用 mock 查询返回值替代存量对账。随后在合并候选源码上使用真实 PG17、两个 Redis 8.2 实例重新运行 `go test -race -count=1 -tags integration ./internal/adminops ./internal/service`；`TestDashboardInventory`、`TestModelWorkflow`、`TestPromptLifecycle` 及服务集成均通过。仍非生产验证。

| 核验项 | 实测结果 |
| --- | --- |
| 目录与发布 | 运营可见尚未发布的生成模型、不能读 `/models`。T11 生命周期用例经真实处理器创建两版、发布、100% 实验、回滚；解析版本与审计断言通过。 |
| 服务存量与版本 | 同模型、任务，窗口内 8 次，三个版本组（含 NULL），每页 1 组逐页累计，与独立 `count(*)` 相等；右端点 1 次被排除。当前发布指向另一版本，历史组仍有 6 次、均耗时 50 ms，失败 1/6，已知 ¥0.625、未知 1 次。 |

| Flutter | `dart analyze`、格式及 release Web 构建。使用 Flutter 3.38.10 的 `flutter_tester` 离线执行全部 7 个 widget 用例通过：含保存新版本、比较、A/B 发布、一次写回滚和数值展示。组件测试的 HTTP 替身只在 test 中；上两行计数证据来自数据库而非替身。 |
