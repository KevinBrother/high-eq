# T20 · 对练与预演界面

## 范围和入口

登录后从 **练习 → 对练与预演**（`/training`）进入。默认 `APP_ENDPOINT=mock`，示例关卡、角色回复和反馈均来自账号生命周期内的内存模拟，不调用模型、不代表实际评分或扣次。真实模式只通过 T16 的鉴权端点及 SSE 解码器访问配置的 App 服务；没有模型 SDK、密钥或直连厂商的路径。

- `app/lib/features/practice/lobby.dart`：复用 T18 的全局场景、关系人可用性及 T17 会员入口。支持难度 1–3、预演描述、续练历史；带关系人的创建/重练在提交前重新校验权限。首次真实练习告知对话与评分保留期；429 不自动购买，保留返回及免费入口。
- `repository.dart` / `demo.dart`：真实与模拟使用相同的页面接口。真实关卡、历史遍历契约分页；创建前把固定请求体保存在 T16 的账号加密续答区。丢响应后点「恢复上次创建」，仍发原 `request_id` 和原输入；放弃本地请求不等于退出一个已创建的会话。
- `chat.dart` / `conversation.dart`：已保存消息与临时气泡分开。`fragment` 不结算；`reply_saved` 后 GET 原会话；`in_progress`、断流、页面重开均先读原历史，已保存则不再 POST，未保存只允许显式重试原 `client_message_id`。发言或结束操作确认前保留账号隔离的操作记录，不自动补发。返回列表不会调用 `/exit`；只有确认「主动退出」才会退出，迟到帧不会重开输入。
- 危机立即用固定求助提示替换流中回复，不显示评分；审核无结论只显示「服务暂不可用，可重试」。评分阶段的安全对象与 503 也分开处理。失败、危机或审核故障读回服务端 `settlement`，区分未扣、已扣及退回**原扣次日**；读回失败不把未知当作退款成功。
- `result.dart`：单项只展示唯一目标、理由、该项得分和 `next_action`；整场显示 NVC 四项、总分、三维等级和理由、原句及改写。`target_turn` 从 1 起只数用户发言。主动重练才生成新会话 ID；重练前一场直接按 ID 取结果，从关卡列表重新开始则按历史顺序取同关、同模式上次已完成成绩。不同关卡或无前次不凑对比。来自别的设备的自定义场景历史没有创建参数，仍能读回对话及结算，不从私密发言猜测情境或关系人。
