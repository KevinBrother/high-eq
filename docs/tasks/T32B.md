# T32B 会员情绪辅助 · 正式客户端装配候选

本增量基于 `cab1c24a3ef0fbfa6c83adcbdb3101a5fe221add`。已登录且通过 T35 账号准入的用户可从「我的」、会员页或语音页进入「情绪辅助」。只读页查询当前账号权益、本人汇总及已授权的历史基线。免费和到期账号仍可走 T32A 快捷标记、历史及 T24 复盘预填。会员或语音页返回时复核权益与授权。账号换租约、汇总请求失效或权益到期会隐藏受限数据。

汇总使用 T25 生成的接口操作与正式会话。汇总的请求有效性贯穿首次发送、401 刷新和重放，当前终态 401 仍走 T35 会话退役。T28 前台健康宿主及回放租约沿用正式基线。只读汇总不等待健康源或语音初始化，显式语音入口使用项目已有语音页。

Dart 决策和进度使用 T30 正式 JSON 向量做离线校验。三个构建开关 `T32B_HEALTH_REPLAY_APPROVED`、`T32B_VOICE_REPLAY_APPROVED`、`T32B_LIVE_FRAMES_APPROVED` 默认关闭。当前正式路由提供只读汇总和历史基线，实时输入与双源回放等待来源验收和接线。

## 手机分项基线进度

有效会员可经「会员与今日额度 → 查看本人情绪汇总」查看四项有效日与今日有效秒，以及 HRV 读数和采样日。页面读取 T30 的当前账号聚合 `GET /v1/signal-baselines`，省略 `for_window`。心率和 HRV 使用健康授权，语速、音量和音调用语音特征授权。授权以同一登录的服务端记录为准，设备状态未知时不判断为拒绝，也不探测传感器。当前手机尚无符合契约的设备端转写来源，历史统计仅纳入 T30 接受的单位。

会员到期、换登录、开始重新读取或读取失败时清除旧进度。服务端当前聚合在同一账号事务内按健康/语音现行授权最小化返回，未授权维度不含读数、天数、基线和阈值。客户端读取聚合前后各复核一次授权，两次都开启才展示对应信号；本进程已确认的撤权立即隐藏对应维度，并在采纳在途响应时再次套用撤权掩码，旧响应不能恢复已撤权数据，其他已授权维度保留。基线请求返回 403 视为权益失效，同时隐藏本轮已通过的会员汇总。授权关闭隐藏对应信号的统计，其余读取故障提供重试。HRV 只呈现历史趋势。跨设备撤权在客户端收到通知或下一次读取前无法瞬时感知，不承诺无通知的一致性。进入或刷新只读页不会申请系统权限、读取设备样本、开始录音或上传窗口。
