# T02 · PostgreSQL 模型

**范围和入口**：`server/migrations/` 四组迁移：账号与测评、训练与评分、聚合信号与手动标记、模型网关。字段、ER 图、保存/删除/导出路径和 TTL 登记存储约束见 [schema](../schema.md)。不包含 API、真实数据或 Go 代码。

**验证**：根目录执行 `./server/tests/migrations.sh`（需要 Docker 和带 postgres driver 的 golang-migrate）。本次在隔离 PostgreSQL 17 上验证：空库应用四组迁移 → SQL 断言 → 全部回滚 → 再次应用。回滚保留迁移工具自己的 `schema_migrations` 和可能由其他模块共享的 `btree_gist` 扩展，不保留业务表。断言覆盖：

- 关联对象不能跨账号；同账号手动标记在 59.999 秒被拒绝，满 60 秒可新建，另一个账号不受影响。
- 单项分不能进入整场成长副本；删复盘同时删副本与关联日志，缺失源不能直接插入新评分；注销不影响其他账号。
- 重复消息与重复扣次被唯一键拒绝；跨日退款能关联原扣次日。订单不能给其他账号发权益，注销清除权益但保留无归属的订单。

**未验证条件**：本卡验证的是数据库约束，不代替 T04 加密/KMS、独立删除登记、导出钩子或 T06 实际结算事务；不声称已运行完整消费者重放、清理定时任务或备份恢复演练。

**下一任务**：T03 根据 `activity_id`（会话/请求 ID）、预分配的 `source_id`、信号渠道和手动标记去重边界写 App/后台契约。T04 在事务与事件消费中遵守 schema 的锁序和删除协议，T34 单独验收灾备。
