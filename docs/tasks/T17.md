# T17 · 登录、首次自评与会员页

## 范围和入口

- `app/lib/main.dart` 按 `Sessions.identity` 重建路由栈：隐私摘要与主动勾选 → 已满 14 岁 → 短信 / Apple（iOS）/ 微信登录。拒绝隐私不发请求；未确认年龄不能取码或发起登录。默认 `APP_ENDPOINT=mock`，验证码只作示例；HTTPS 地址切换整套真实服务。账号变化时旧页面和待发操作不可复用。
- 自评单独同意；暂不测评仍可进入练习。「练习 / 成长 / 我的 → 本次自评与续答」进入 `/assessment`。按服务端版本加载 16 题、7 个选项，每次选答案即存再前进，可回看。`AssessmentBook` 使用 T16 的账号级 AES-GCM 续答，保存版本、答案、位置及 T18 场景；换题库不套用旧答案，退出账号清除。提交只传题库版本和答案；场景在本次会话共享，不写进答卷 API。
- `AssessmentRadar(percentages: …)` 位于 `app/lib/features/onboarding/radar.dart`。按 SEA、OEA、UOE、ROE 四个 key 传原始 0–100 的 `double`；图上标四轴，大字与读屏另有数值和分档文案，**不能传取整后的展示值**。展示「本次自评」，不作诊断；复测取 `next_eligible_at`，跨设备重复提交按 409 的 `retry_at` 显示倒计时。
- 「我的 → 会员与今日额度」：免费/会员权益、三项 AI 额度、用尽与重置时间；免费手动标记和历史不占额度。当前版本不渲染自动提醒卖点，服务端返回 true 也不能越过 T36。没有采集代码、健康或麦克风系统授权。
- `features/membership/store.dart` 负责支付顺序，`cn.higheq/mobile-commerce` 为原生边界。iOS 用当前会话的 `getPurchaseToken` → StoreKit 2 `appAccountToken` → 签名交易 → `restorePurchase` 服务端核验 → `finish`；恢复不改签、不重绑。409 提供验证/切换原账号的操作；取消或待批准不解锁。安卓微信/支付宝月/年卡为一次性购买；订单请求 ID 按账号、渠道、套餐加密保存供重试。返回或手动刷新都从服务端取权益，不以 SDK 回调判定开通。

## 未验证条件

- 未使用私人账号、真实 SMS、实际商户、签名供应商 AAR 或线上扣款。默认 Android contract 构建缺配置时明确不可用；iOS 没有有效 SKU 同样不发起购买。未验证正式隐私主体/联系方式；发布前应替换开发协议并同 T05 对齐版本。
- **iOS 沙箱清单**：为发行 bundle/签名启用 Sign in with Apple、In-App Purchase；准备同组自动续期月/年 SKU，设置 `SUBSCRIPTION_MONTHLY` / `SUBSCRIPTION_YEARLY`。微信另接审核通过的 `WechatOpenSDK`、App ID、已验证 Universal Link、Associated Domains/URL Scheme；设置 `WECHAT_APP_ID` / `WECHAT_UNIVERSAL_LINK`。T05/T07 真实适配器和商店服务端凭据就绪后：账号 A 月/年购买、取消、待批准、杀进程/重装恢复；用 B 恢复同笔交易必须提示冲突，B 无权益；切回 A 再恢复；续期、过期、退款均以服务端读回为准。
- **安卓沙箱清单**：配置测试商户、App ID、包名/签名及回调域名；按外部批准的 SDK 锁定版本和校验和。仅在私有 Gradle 配置设置 `t17VendorSdk=true`、`wechatAppId`、`wechatSdkAar`、`alipaySdkAar`（本机绝对路径），构建 vendor 源集并先验证包的签名。分别测试月/年下单、取消、未装客户端、回到前台、延迟/重复通知、重复点击与断网重试；核对 T07 `/orders` 下发 payload 与商户 SDK 字段，T06 权益到账后才展示会员。发布前在另一端用同账号复核；商户私钥不进 App。
- **三分钟人工验收**：冷启动并清空测试身份，请首次使用者阅读、完成登录和 16 题；从首屏到看到雷达计时，记录设备/网络/登录渠道、短信耗时、停顿题号与是否超过 180 秒。另在第 8 题杀进程、回到原账号应续答；换号不见 A 的答案。本卡没有把自动点击当此项签收。
