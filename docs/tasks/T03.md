# T03 · API 契约

**范围和入口**：[App](../api/app.yaml) 66 个操作，[后台](../api/admin.yaml) 14 个操作，均为独立 OpenAPI 3.0.3 文件。按 `operationId` 定位，`x-example-request` 是请求行示例；参数、请求体、各状态回应的示例在操作内或其引用组件中。`sendMessage` 的 `x-event-schemas` 约束各 SSE 帧 `data:` JSON。后台不暴露用户/订单管理或明文密钥。[事件目录](../api/events.md) 规定测评、整场评分、单项进度、反馈及删除/导出钩子的发布方、订阅方与载荷。

**验证命令及实际结果**：仓库根运行以下命令（Python 3.12、Go 1.26；验证用生成器版本不代替 T04 锁依赖）：

```sh
python3 -m venv /tmp/high-eq-contract-venv
/tmp/high-eq-contract-venv/bin/pip install -r scripts/contract-requirements.txt
/tmp/high-eq-contract-venv/bin/python scripts/check_contracts.py
go install github.com/oapi-codegen/oapi-codegen/v2/cmd/oapi-codegen@v2.5.1
PATH="$(go env GOPATH)/bin:$PATH" ./scripts/check_contract_codegen.sh
```

本地结果：App 66、后台 14 个操作均通过规范与示例校验；SSE 的 5 种帧按各自的 JSON schema 校验；配额、危机/故障分流、会员/免费标记和拒收原始传感器输入的断言通过。两个包都在临时目录生成 models/Gin ServerInterface 并通过 Go 语法检查，无生成代码提交。GitHub Actions `Verify` 新增独立的 `OpenAPI examples and Gin code generation` 作业；用 `gh run list -w Verify --commit <本卡提交 SHA>` 定位该提交的线上证据。

**未验证条件**：本卡不实现 HTTP 处理器，不代表已完成 SDK 编译联调、结算/退款事务、真实渠道签名、会员检查、传感器权限、真机或苹果审核。支付示例是占位报文而非可验签凭据。删除/导出与防重放在此仅定义协议，不把静态检查当作并发或灾备验证。

**下一任务及注意事项**：T04 独立开卡生成两个包，采用事件目录并将其引入 CONVENTIONS；鉴权从令牌取用户，知道源 ID 不等于拥有权限。T16 可按 App 契约模拟；已审核片段不等于完整回复保存，断线不等于退出。窗口按账号、30 秒起点和渠道标识；免费标记与会员采集/画像汇总分离。后续模块如需改协议，同步修改对应 YAML、示例和校验。
