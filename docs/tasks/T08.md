# T08 · WLEIS 测评服务

## 范围和入口

- `server/internal/assessment/` 实现计分、写入、历史、隐私钩子和完成事件补投。默认离线加载 `wleis.yaml`：题目、原文、译文、维度与顺序来自 `docs/wleis_items.md` 的 YAML，另含七个中文选项。可用 `WLEIS_CONFIG_PATH` 指向同格式的只读文件（容器内路径），重启即生效，无需改 Go。换题必须换版本，旧版草稿不按新题序计分；坏配置阻止启动，历史分数不随题库更新重算。
- 启动沿用 `./server/dev.sh`。三个操作沿用 `docs/api/app.yaml`，均需本人 Bearer。`GET /v1/assessments/instrument` 返回当前版本、16 题和选项，不采集答卷。提交前由本人通过 T05 的 `PUT /v1/me/consents/assessment` 单独授权；注册同意、会员权益不能替代。`POST /v1/assessments` 收 `{version, answers}`；非当前版本、缺题、多题或非 1–7 整数返回 400，不保存部分答卷。未授权或已撤回返回 403。历史走 `GET /v1/assessments?limit=20`，按完成时间、ID 倒序，下一页传 `next_cursor`；历史不回传答卷，撤回采集不等于删除已有记录。
- `dimensions.SEA/OEA/UOE/ROE` 和 `total` 返回 `mean, percent, display, level`。百分制从题分整数和直接换算，在 40/60/75/90 处分档后才四舍五入。雷达与比较是**本次自评**，不是诊断；不用模型，不生成训练计划，不改 T17 页面或端侧续答。
- `WithSession` 在同一事务持账号锁，随后检查独立同意、读取最近保留的完成时间和数据库时钟、计分落库。满 **672 小时**可提交，未满返回 409 `conflict` 和精确的 `retry_at`。答卷、原始精度得分分别用 T04 AES-GCM 信封保存，AAD 绑定表、字段、账号、测评 ID、题库版本。
- 迁移 `20261121204508_assessment_delivery`：提交时在源行设置 `completion_pending`；源事务提交后才投递 `assessment.completed`，只含 `user_id, assessment_id, occurred_at`。无订阅者或订阅失败保留待投状态，不要求用户再次提交。API 进程的分钟维护循环在有订阅者时补投；在账号锁内重读源时间，订阅写入与清位同事务。删除源即删除待投状态，不单独留答案、事件副本或复测标记。
- `assessment.Hooks` 加入必需清单。协调器按单源或账号删除，钩子核验无残留；导出按本人逐条解密写 `assessments.json`，含原答卷、版本、时间、维度和总分。失败则不把截断 ZIP 当完成。不新增删除/导出 HTTP 入口。
