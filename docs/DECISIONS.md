# 本轮决策摘要

| 事项 | 决定 | 执行入口 |
| --- | --- | --- |
| 平台 | Flutter iOS/安卓、Flutter Web 后台、Go 单体、PostgreSQL + Redis；本轮不用对象存储，不做鸿蒙。 | T01–T04、T16、T34 |
| 权益 | 免费可点“我上头了”并看记录，60 秒内去重，不扣次；可建 1 个关系人；对练、回复助手、文字复盘各每天 3 次。会员跨平台生效，另享个性化计划、传感器采集、录音与心率对齐回放及按对象/场景汇总的个人情绪画像。 | T06、T07、T17 |
| 扣次 | 对练按会话 ID 结算，首条完整回复审核通过并保存才扣；评分失败、危机或审核故障净扣零；故障显示“服务暂不可用，可重试”，不作危机提示；按消息/请求幂等。 | [共用扣次表](standards/quota.md) |
| 评分 | 单项只记目标项进度：25 分过关，10–24 分三天后重练，低于 10 分当场再试；训练参考分只纳入整场对练、完整复盘。WLEIS 按未取整百分值分档，展示本次自评。 | [评分规范](standards/scoring_prompt.md)、T12、T26 |
| 情绪提示 | 实时心率异常和语音异常同时出现才可提示本人波动；仅两类语音异常只提示对话节奏，不自动更新个人画像。安卓本轮只支持后者。 | [判定表](standards.md#五生理与语音辅助标准)、T30、T32B |
| 手表 | T36 技术验证通过即可开发/送审，苹果正式放行前不启用也不宣传自动提醒。T32A 免费标记在 P5 先交付，T32B 会员功能后交付。 | T36、T17、T31、T32A/B |
| 数据 | 录音仅本机保留 3 天；服务器不收逐条传感器读数；评分理由只在源评分明细，日志和成长侧不复制原话。导出、删除覆盖清单中可关联的副本；删除记录仅含源 ID，覆盖重放期与最长备份期；恢复后先重删再开放。 | [隐私清单](standards/privacy.md)、T02、T35 |
| 身份 | 内部用户 ID 唯一；设置手动绑定，冲突不自动合并；iOS 购买用 appAccountToken 关联归属。 | T05、T07、T17、T35 |
| 外部服务 | 模型和审核只用境内处理且不出境的国内服务；主备同标，优先可签不留存/短期留存条款。 | T09、T10、T14、T33 |

任务卡写明实施和验收要求；本页仅作索引，不另设覆盖任务卡的补丁。
