# 隐私政策要点与授权流程

心率、HRV、语音特征和情绪相关数据按敏感个人信息处理：每类都要在用到时单独弹窗取得同意，并说明必要性和对用户的影响。本页是产品侧草案，正式的隐私政策和用户协议上线前须由律师审阅。

## 法律要求（《个人信息保护法》）

| 条款 | 要求 | 对产品的意思 |
| --- | --- | --- |
| 第十七条 | 处理前以显著方式、清晰易懂的语言告知处理者身份和联系方式，处理目的、方式、信息种类、保存期限，以及行使权利的方式 | 首次启动弹窗 + 完整隐私政策 |
| 第二十八条 | 医疗健康信息、不满 14 周岁未成年人的信息属于敏感个人信息，只有目的特定、确有必要并严格保护时才能处理 | 心率、HRV 等按敏感信息处理，只采集判定必需的项 |
| 第二十九条 | 处理敏感个人信息要取得单独同意 | 不能合并在总体隐私政策同意里 |
| 第三十条 | 还要告知处理敏感信息的必要性和对个人权益的影响 | 每个单独同意弹窗都写“为什么需要”和“对你的影响” |
| 第三十一条 | 处理不满 14 周岁未成年人信息要取得监护人同意，并有专门规则 | 本轮不面向未满 14 周岁用户，注册时确认年龄 |

**删除与导出验收（T02、T04、各数据模块、T35）**：按表逐类导出用户仍有的服务端数据，包含源消息、带引用的评分、数值副本及可关联的调用记录，不含他人账号数据或平台密钥。删除会话、复盘或关系人时，按源 ID 清除其相关消息、评分、成长副本和可关联日志并重算；注销冷静期满后遍历所有模块。用同一测试会话做“导出 → 删除 → 再导出”，逐项核对；本机录音不为导出而上传。日志规则同样适用于超时、备用模型和错误重试，不得把原文写入错误日志。

**删除后防重放**：删除会话、复盘或注销清理账号时，先登记被删除的评分事件源 ID，再清除关联记录；删除和消费须保证并发下也不会重新写入。防重放记录的业务字段仅有不含身份信息的源 ID，不留用户 ID、时间线、分值、理由或正文，不提供给成长档案或用户导出。事件最长可重放期为 30 天。删除记录从删除时起至少覆盖 `max(30 天, 任一可恢复备份的最长保留期)`；延长备份保留前先保证删除记录覆盖，期满清除；过期事件不再消费，即使防重放记录已清除，也不得根据事件重建不存在的源记录或账号。

反序验收：① 删除复盘并重算，重放旧评分事件，训练参考分保持删除后的值，再导出仍无该条；② 账号注销清理完成后重放其旧评分事件，不重建账号、评分副本或可导出数据。两组均覆盖窗口内重复投递和窗口外过期投递。

**备份恢复（T34、T35）**：覆盖账号及各源数据删除，仍只保留执行删除所必需的不透明源 ID，不存正文或评分。删除记录独立于待恢复快照，不能随业务库一起回滚。恢复在隔离环境执行：加载最新删除记录 → 重做删除及副本清理 → 核对已删复盘不可查询/导出、已注销账号不可登录或恢复 → 才开放流量和消费者；无法证明覆盖完整则保持关闭。

**设备端（T16、T24、T28、T29、T35）**：草稿、测评续答、本地录音和待发窗口按内部用户 ID 隔离。A 退出后 B 不可读取或补传 A 的数据；撤回时清空该采集项未发送窗口，联网后不补传；App 关闭超过 3 天，重开先清过期录音再展示或播放。手动标记历史不因撤回传感器权限消失。

**模型与审核服务准入（含备用）**：仅用境内处理、存储、不出境的国内服务；登记发送字段、用途、处理地区、最长留存、关闭留存/删除途径及条款凭据。优先可签不留存或明确短期留存条款者；条款或数据去向不清不启用，主备执行同一标准。人工评分抽检只在受控环境进行，缺陷用虚构案例复现；真实对话、引文及身份关联键不进评测库。

**账号归属**：手机号、Apple、微信均是登录方式，内部用户 ID 才是唯一身份。已有账号在设置里手动绑定，已属其他账号的身份不自动合并；恢复内购须核验 appAccountToken 与原账号的关联。

## 授权流程

1. **首次启动**：弹出隐私政策和用户协议摘要，用户点“同意”后才进入，勾选框默认不勾；不同意则只能退出。
2. **注册**：确认已满 14 周岁，未满则不能注册。
3. **首次测评前**：单独同意弹窗，说明答卷用于生成雷达图和训练计划。
4. **开启手表功能**：先弹 App 自己的单独同意（采集什么、为什么需要、对你的影响、随时可关），同意后再触发系统的健康数据权限。
5. **开启语音功能**：说明提取的数字可能混入对方声音、不能据此认定本人情绪；同样先弹单独同意，再触发系统麦克风权限；录音时屏幕上始终有状态提示。
6. **打开录音保留**：再弹一次单独同意，写明“录音会包含对方的声音，仅保存在本机 3 天，建议告知对方”。
7. **首次对练、复盘、粘贴聊天记录或添加关系人**：提示内容含他人信息，说明保留时间。
8. **设置页**：每项同意都能单独撤回；提供数据导出、删除和注销（注销有 15 天冷静期）。

## 隐私政策须包含的章节

- 公司名称和联系方式（含个人信息保护负责人联系方式）
- 按功能列出收集的信息、目的、方式和保存期限（即上面的数据清单）
- 敏感个人信息的必要性和对用户的影响
- 接入的第三方 SDK 和服务（大模型、支付、短信、内容安全、健康平台）及其处理的信息
- 用户权利：查阅、复制、更正、删除、撤回同意、注销，以及各自的操作路径
- 未成年人保护说明
- AI 生成内容说明：建议仅供参考，不是心理诊断
- 政策更新时如何通知
