# 对练扣次表（T03、T06、T12、T19、T20 共用）

免费对练按用户时区的自然日计数，一场以 `session_id` 唯一标识。只有第一条 AI 回复**完整生成、整条审核通过、已持久化且可按该会话 ID 取回**时才记一笔；首个 token、已显示的句子和客户端是否收到都不是扣次依据；以下是**同一场的最终净扣次**，不是第二次收取。会员不限次。回复助手和文字复盘另按各自成功请求计次，不混用对练账本。

| 会话结果 | 最终净扣次 | 动作 |
| --- | ---: | --- |
| 正常完成并取得评分 | 1 | 保留已扣次数。 |
| 首条完整回复审核通过并保存后，用户主动退出 | 1 | 保留已扣次数；仅断线不视作退出。 |
| 首条回复只显示了部分内容便失败，或用户在首条回复保存前退出 | 0 | 释放占用名额；退出生效后迟到的生成结果不得再扣。 |
| 首条回复生成完，审核明确命中危机 | 0 | 按危机终止，不保存为成功回复、不扣次。 |
| 首条完整回复审核通过并已保存，但客户端断线未收到 | 1 | 重连按原会话取回同一回复，不再扣。后续若评分失败或危机终止仍按下表退款。 |
| 结束评分最终失败 | 0 | 已扣则退回原扣次日；未扣不退。 |
| 危机终止（含评分阶段） | 0 | 立即终止；已扣则退回原扣次日。 |
| 审核服务超时、不可用或无结论（任何阶段） | 0 | 立即停止流并用“服务暂不可用，可重试”替换已显示内容，不发危机提示。未扣则不扣，已扣则幂等退回原日。 |
| 断线、重发或重复回调 | 不变 | 同一 ID 恢复历史和已有结算，不重复扣、不重复退。主动重练才创建新 ID。 |

手动标记和查看历史不调用模型，也不占任何 AI 配额。打开复盘页或保存草稿不计次；从标记进入后，仅用户提交 AI 文字复盘且成功时计一次文字复盘，失败或危机不扣。

验收：并发首次回复、重复结束、重复退款、跨零点退款及断线重连均以同一会话账本断言；失败或危机退款不能增加次日额度。T12 返回评分状态，不直接改余额；T19 把会话结果交给 T06 结算。

**重试粒度**：`session_id` 标识一场，`client_message_id` 标识该场的一条用户消息；回复助手、AI 文字复盘各用 `request_id`。相同操作重试时读取已完成结果或进行中状态，不新增消息、评分或扣次；审核故障允许恢复同一操作重试，而不是绕过审核。已向客户端输出片段的回复不再拼接备用模型输出。
